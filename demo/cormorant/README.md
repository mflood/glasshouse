# DSV Cormorant demo

This deliberately fictional incident corpus demonstrates recorded,
sentence-level evidence ablation; closed-book comparison; coalition
attribution; source-span recovery; and the committed attribution,
counterfactual, and injection evaluation suites.

The demo adds only frozen inputs, recording data, evaluation keys, and a
presentation fixture. Glasshouse establishes whether generated claims depend
on supplied evidence; this demo does not establish that a claim is true,
fully entailed, reliable, or authoritative.

The corpus is fictional and repository-authored under the repository license.
Its recording, vectors, questions, probes, and independent labels are committed
here so replay and evaluation remain deterministic without an API key.

This demo follows the repository [demo charter](../CHARTER.md).
